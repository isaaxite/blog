# 第一章

主要人物是 霍塞-阿卡迪奥-布恩地亚，他带领族人（不是全部，仅是愿意追随他的部分人）包括他的妻子乌苏拉-伊瓜朗，以及途中诞下的与他同名的大儿子，历经26个月为寻找海口而踏上旅途，但最后因困难而放弃而到达无名地方。并在此地扎根，建立起名为马贡多村落。在14年或更多的时间内，霍塞在马贡多，带领众人积极发展，使得村落越发繁荣，有秩序。期间由于吉普赛人的到来，霍塞认识了他一生的好友——墨尔基阿德斯。墨尔基阿德斯期间不断教授霍塞新知识，而霍塞的热情也转移到了包含炼金术、磁石、天文等等新知识中，他投入巨大的热情以至于他的好友们（一同建立村子的好友）甚至认为他已经疯癫。但以我们现在的眼光来看，霍塞是聪明睿智，有远见，善于思考与总结的，他甚至凭借有限的资料自行推算出地球是圆的！

霍塞是充满探索精神的。在获得天文知识，懂得辨别方向的知识后，就迫切地带领人员往外探索，以往建立文明世界与马贡多的联系。虽然这趟旅途的目的未达成，以如命运愚弄般的方式结束——他在探索旅途的终点发现了海口。这没有让他高兴，因为他虽然勇敢，但不觉得自己有能力或有必要牺牲同伴去征服海洋去建立路线铜像文明世界。这趟旅程让他沮丧，甚至让他想要另择新址建立马贡多，他意志坚定到甚至只有他的家人也要前往，讽刺的是也是家人让他放弃了转移的想法。将精力放到自己不曾理会的两个儿子身上（在建立马贡多后诞下二儿子，奥雷良诺（与霍塞父亲同名））
# 第二章

交代了霍塞与乌苏拉为结婚前的关系——表兄妹。由于近亲结婚引发了不少的闲言与冲突，最终以村民，普罗登肖-阿基拉尔，的死亡结束了他们的婚姻问题。他们选择离开村子去往被命运指引的马贡多。

在马贡多两个儿子在不断成长。大儿子霍塞-阿卡迪奥已经到达性征发育的发情的年纪，与外来迁入的村民庇拉-特内拉发生了关系，庇拉年幼时被强奸，因此思想变得扭曲，滥交，也因此不下一次与小霍塞发生关系，直到庇拉怀上孩子。得知将初当父亲的小霍塞是恐惧的，以至于为逃避这一切而独自偷偷地跟着吉普赛人离开。小霍塞的失踪，最大反映的是乌苏拉，她无法接受，慌忙下，她抛下丈夫霍塞、小儿子奥雷良诺以及小女儿阿玛兰塔独自踏上了寻找小霍塞的旅途。不知道是不是作者喜欢使用讽刺的写法，人物的目的大多与结果想去深远，却又是某次期望的结果，让人感到实实在在地存在着命运对人的操控与愚弄，这趟旅途没有找回小霍塞，反而找到了马贡多与外界联系的道路

# 第三章

小霍塞离开后，庇拉生下了他们的儿子并交由乌苏拉一家抚养，并使用了这孩子父亲的名字——霍塞-阿卡迪奥。

霍塞的生活重新从炼金术中重新转移回马贡多建设上，在他的带领下，小镇变得越发地繁荣，规模也更大，秩序整然。

雷蓓卡，乌苏拉远方表妹的遗孤来到马贡多，投靠他们一家，尽管事实仍然存疑，但他们还是接受这个小孩，作为家庭的新成员。她年纪略大于阿玛兰塔，因此成为了两个小孩的姐姐。雷蓓卡经历了很多，初期甚至无法融入新家人。不说话、不进食、吃土等问题困扰着乌苏拉。她没有放弃雷蓓卡，而是以自己方式误打误撞地导其向正途。

外来的雷蓓卡带来了失眠症，是具有传染性的疾病。让人无法入睡外，随着时间的推移还会让人失忆直到忘记一切。失眠症最终肆虐整个小镇，失忆的问题越发显现，大家无法杜绝，只能使用一些蹩脚的，甚至是滑稽的方式——对忘却的事物做标注——应对，尽管他们知道这是治标不治本的。失眠症让整个小镇陷入混乱，霍塞一家也不例外。它最终由“死而复生”再次到来马贡多寻找霍塞的墨尔基阿德斯带来的药水结束。

墨尔基阿德斯现已孤身一人，据说被部落抛弃。他也已然无心继续漂泊，觉得在马贡多，霍塞家扎根。带着他新的设备——摄影机，并在霍塞家建立铜版摄影实验室。霍塞对墨尔基阿德斯带来的新事物相当感兴趣，迷恋上它，甚至期望借此发现上帝的身影。霍塞的生活重心再次转移！

随着时间的推移，孩子们也长大，雷蓓卡已然成为美人，阿玛兰多也显现出她祖母的傲气，奥雷良诺的炼金术——给饰品镀银——也变得出众，小霍塞（霍塞的孙子）也成为奥雷良诺的助手。乌苏拉开始觉得房子拥挤，并计划扩建房子，也确实热情慢慢地执行。

马贡多的第一任镇长到来。经历了无流血冲突后，镇长堂阿波利纳尔-莫科特带着7个女儿与妻子正式进入落户马贡多。

# 第四章

扩建的房子建成，为庆祝乌苏拉准备许多东西，其中就有一架自动钢琴，随它而来的还有调试钢琴的皮埃特罗-克雷斯庇。在他懂钢琴和舞蹈，因此也教授两姐妹（阿玛兰塔和雷蓓卡），一来一回间情愫自生于三者之间。皮埃特罗与雷蓓卡互通书信，也因此爱意越浓。而阿玛兰塔虽然倾心于皮埃特罗，但却未踏出一步。直到雷蓓卡于皮埃罗的事情被乌苏拉偶然发现，同时也被阿玛兰塔发现。随着雷蓓卡与皮埃特罗的婚事定性，她向皮埃特罗表达爱意被拒后，她的爱意转变为恨意。她极端地恨着这对情侣，不下一次进行言语恐吓与诅咒。乌苏拉为此头痛，更让她头痛的还有奥雷良诺表达出对堂阿波利纳尔小女儿雷梅苔丝的爱慕，并意欲上门提亲。好在几经操作后，婚事达成。乌苏拉一家以及堂阿波利纳尔一家竟然认可这桩年龄差距颇大的婚姻是让我惊讶的，他们甚至没有多大的不愿意的情绪，透露出野蛮感！

墨尔基阿德斯已经是个垂暮老人，死期到来。他的死亡让霍塞-阿卡迪奥-布恩地亚难以接受，在发现墨尔基阿德斯的尸体后，甚至不相信他已经逝去，认为还有复活的可能直到他使尽解数才愿意下葬这位他的一生的挚友。期间，乌苏拉发现阿玛兰多对皮埃特罗的爱意以及对恨意，决意带上她外出旅行以避免姐妹的冲突，也意在可以籍着旅游转移阿玛兰塔的注意。乌苏拉的离开对失去挚友的霍塞是雪上加霜的，他不断沉湎去悲伤，以至于失去理智，变得神智不清，沦为疯子，最终囚于院子里的栗子树下

# 第五章

## 关键事件

- 雷梅苔丝成年，与奥雷良诺完婚；
- 雷蓓卡与皮埃特罗的婚礼本应与奥雷良诺的同一天进行，但因为因为阿玛兰塔从中作梗而以再推迟；
- 失踪的霍塞-阿卡迪奥回归；
- 雷蓓卡移情别恋，爱上归来不久的霍塞，并火速完婚；
- 马贡多出现政治冲突（自由派与保守派），最终导致奥雷良诺带领村民起义反抗，出发加入革命军部队，成为奥雷良诺上校。

雷梅苔丝第一次来月事就不顾礼仪地当众告诉奥雷良诺。可见，她俩之间是订婚后不断的相处而培养出深厚的爱意。婚后雷梅苔丝的转变是巨大的，由懵懂、纯粹的少女转变为面面俱到，温柔、体贴、贤慧的女性。这种转变是突兀的，硬要合理化地解释是她是个聪慧的女子。

为了阻止雷蓓卡的婚礼，阿玛兰塔展现出越发极端行为、想法和言语，旅行对她毫无作用。最终，疯狂到在咖啡中下毒（鸦片酊），间接或直接地导致了雷梅苔丝和她腹中双胞胎的死亡。阿玛兰多展现出的极端的程度令人费解，完全不顾及姐妹之情，完全地被妒忌和恨意占据、驱使。她的疯狂是莫名的。她并没有她想象中那么爱皮埃特罗——从后面雷蓓卡移情别恋，皮埃特罗向她求婚，而她拒绝可见，尽管姐姐和霍塞完婚也继续怨恨着姐姐。她对姐姐的恨意到底来源什么？我看来是病态的！ 

失踪已久的霍塞（奥雷良诺的哥哥）归来。他的出场描述是地动山摇的，这是不是我夸张的描述，而是物理上的书中的旁白如此。作为现实的人来说，这是奇怪的，毕竟一个人无论如何强壮。如何施展拳脚都不会达到此等超人的效果！我只能归结为这是一种预兆，或许他的归来将会给这个家庭带来动荡。动荡是有，但却低于我的预期（对比之前这家人的种种奇异与超出普通人的行为）——他与雷蓓卡搞在一起，并结为夫妇。他是个代表野蛮的，无视道德的。我暂未分清他是原本即不懂道德，还是在具备后无视的。他的日常，与现代或当时他身处环境的其他人是不同的，种种行为都表示他是被自己的欲望驱使的。

马贡多的转变是突然的，突然引入的政治矛盾。像是一把刀突然插入到马贡多这块健康血肉中，不断搅拌，牵动着众人的命运。其中最大转变的是奥雷良诺，给人的感觉他不久前还是个平和享受家庭温暖，淹没于丧妻痛楚的抗拒冲突的普通人，在猛烈到来的政治冲突中快速地拿起了枪成为了革命的带领者，习惯于杀人的老士兵！
